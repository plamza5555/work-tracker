สำหรับใช้งานส่วนตัว
# 📋 Changelog - บันทึกประวัติการพัฒนา Work Tracker

รวมประวัติการอัปเดต ฟีเจอร์ใหม่ และการปรับปรุงประสิทธิภาพของระบบ **Work Tracker (ปฏิทินบันทึกงานรายวัน)**

---

## 🚀 [v1.5.0] - 2026-11-24 (ล่าสุด)
### ✨ ฟีเจอร์ใหม่ (New Features)
- **ระบบแนบไฟล์และเชื่อมต่อ Google Drive (File Attachments & Google Drive)**:
  - เพิ่มปุ่ม **"แนบไฟล์"** ข้างปุ่มเลือก Tags รองรับทั้งไฟล์รูปภาพ (`.jpg`, `.png`, `.webp`, `.gif`) และไฟล์เอกสาร (`.pdf`) สามารถแนบทีละหลายไฟล์ได้
  - เชื่อมต่อการอัปโหลดไฟล์ตรงเข้าสู่โฟลเดอร์ Google Drive **"จัดเก็บเอกสาร"** อัตโนมัติเมื่อลงชื่อเข้าใช้ด้วย Google
  - มีปุ่มทางลัด **"Drive"** เปิดตรงไปยังโฟลเดอร์ Google Drive ได้ในคลิกเดียว
  - **ระบบ Hover Preview (พรีวิวเมื่อเมาส์ชี้)**:
    - เมื่อเอาเมาส์ไปชี้ที่ป้ายชื่อไฟล์รูปภาพ จะแสดงภาพตัวอย่าง (Thumbnail) ลอยขึ้นมาให้ดูทันที
    - เมื่อชี้ที่ไฟล์ PDF จะแสดงการ์ดเอกสารพร้อมชื่อไฟล์ ขนาดไฟล์ และสถานะการจัดเก็บ
    - สามารถคลิกที่ไฟล์เพื่อเปิดดูไฟล์เต็มหรือเปิดใน Google Drive ได้
  - **ระบบจัดเก็บออฟไลน์ (IndexedDB Storage)**:
    - หากไม่ได้ต่อเน็ตหรือยังไม่ล็อกอิน Google ไฟล์จะถูกบันทึกลงในฐานข้อมูล IndexedDB ของเครื่อง ทำให้ดูพรีวิวได้ตลอดเวลาและไม่ทำให้โควตา LocalStorage เต็ม
  - เพิ่มไอคอนคลิปหนีบกระดาษ `📎` บนการ์ดงานในช่องปฏิทิน เพื่อให้สังเกตได้ทันทีว่างานใดมีไฟล์เอกสารแนบอยู่

### 🐛 การแก้ไขข้อผิดพลาด (Bug Fixes)
- **แก้ไขปัญหาปุ่มลัด `Ctrl + Z` กดไม่ติด**:
  - รองรับการตรวจจับปุ่มจริงบนคีย์บอร์ด (`KeyZ` / `keyCode 90`) ทำให้กด `Ctrl + Z` ได้ 100% แม้จะกำลังเปิดแป้นพิมพ์ภาษาไทย (ปุ่ม ผ) อยู่ก็ตาม
  - แก้ไขฟังก์ชัน `renderStats` ที่ค้างในโค้ดเดิม ทำให้กระบวนการ Undo ทำงานลื่นไหลไม่เกิด Error
  - ปรับปรุงให้กด `Ctrl + Z` ย้อนกลับงานได้ทันที แม้เคอร์เซอร์จะยังกะพริบอยู่ในช่องกรอกข้อความที่ว่างเปล่า

## 🏖️ [v1.4.0] - 2026-11-24
### ✨ ฟีเจอร์ใหม่ (New Features)
- **ระบบกู้คืนประวัติ Undo (Ctrl + Z & ปุ่มย้อนกลับ)**:
  - เพิ่มการ์ดแจ้งเตือน (Popup Toast) ที่มุมซ้ายล่าง แจ้งเตือนทุกครั้งที่มีการแก้ไข/ลบ พร้อมปุ่มกด **"ย้อนกลับ (Undo)"**
  - รองรับการย้อนกลับทั้งการสร้างงาน, แก้ไข, ลบงาน, สลับวันหยุด และการลากย้ายวัน
- **โหมดกำหนดวันหยุด (Holiday Mode 🏖️)**:
  - เพิ่มฟังก์ชันคลิกเปิด-ปิดวันหยุดประจำวัน
  - แสดงไอคอน `🏖️ วันหยุด` พร้อมไฮไลต์สีพื้นหลังช่องปฏิทินให้สังเกตง่าย
- **เวอร์ชัน Template สำหรับแจกจ่าย (Clean Release)**:
  - แยกโฟลเดอร์ `Template/` สะอาดพร้อมแชร์ต่อ ไม่มี API Key ส่วนตัว และไม่มีตารางงานตัวอย่างติดไป

## ☁️ [v1.3.0] - 2026-11-24
### 🔄 ซิงก์ข้อมูลข้ามอุปกรณ์ (Cloud Sync & Multi-Device)
- **เชื่อมต่อ Firebase Realtime Database**:
  - รองรับการซิงก์ข้อมูลงานระหว่าง **คอมพิวเตอร์ และ มือถือ** แบบเรียลไทม์ (แก้ไขฝั่งหนึ่ง อีกฝั่งอัปเดตทันที)
  - เชื่อมต่อเซิร์ฟเวอร์สิงคโปร์ (`asia-southeast1`) เพื่อความรวดเร็วสูงสุด
- **ระบบเข้าสู่ระบบด้วย Google (Google Sign-In)**:
  - รองรับการล็อกอินด้วยบัญชี Google ทั้งบนคอมพิวเตอร์และมือถือ
- **ไฟล์ตั้งค่าอัตโนมัติ `firebase-config.js`**:
  - ใส่ค่า Config ในไฟล์เดียว ทุกเครื่องและมือถือพร้อมใช้งานทันทีโดยไม่ต้องตั้งค่าในหน้าเว็บซ้ำ
- **สถานะการเชื่อมต่อ (Connection Indicator)**:
  - แสดงสถานะสด: `🟢 ออนไลน์`, `☁️ กำลังซิงก์...`, `🔴 ออฟไลน์`

## 🔀 [v1.2.0] - 2026-11-24
### 🖱️ ปรับปรุงระบบลากและวาง (Drag & Drop Enhancements)
- **ลากย้ายงานทั้งวัน (Whole Day Drag & Drop)**:
  - สามารถคลิกลากที่หัววัน (`+ อีก X งาน (ลากทั้งวันได้)`) เพื่อย้ายงานทั้งหมดในวันนั้นไปยังวันอื่นได้ในคลิกเดียว
- **ลากย้ายงานรายชิ้น (Single Task Drag & Drop)**:
  - รองรับการลากการ์ดงานเดี่ยวข้ามวันอย่างลื่นไหล
- **ปรับแต่ง Layout หน้าต่างจัดการงาน (Day Modal 2-Column)**:
  - แบ่งฝั่งซ้ายเป็นฟอร์มเพิ่มงานและตัวกรอง ฝั่งขวาเป็นรายการงานเพื่อความสบายตาและใช้งานง่าย
